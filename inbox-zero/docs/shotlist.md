# Neura Chat: Inbox Zero — shot list
30 s · 120 bpm · 60 beats (1 beat = 0.5 s) · format: 9x16 · Music: synth house, F minor, builds at beat 16 · VO: none

**Idea.** Unread WhatsApp chats pile up (12 → 47 → 99+) until the inbox overflows. Neura Chat switches
on and clears it, chat by chat, in rhythm, back to **0**. Satisfying, not scary.

**Look.** Website world: lavender paper `#F5F2FF`, ink `#15112A`, one accent Neura violet `#6A3DF0`
(WhatsApp green only on the unread badge, because that is what it is). Display: Plus Jakarta Sans 800, UI: Inter.
Chat rows are drawn as simple type + shapes (a generic inbox), never as a fake Neura Chat screen.
Every Neura Chat moment uses a real screenshot.
